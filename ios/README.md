# Xcode에서 가상 시편 앱 실행하기

SwiftUI·SceneKit 기반 가상 콘크리트 시편 앱입니다. `ContentView.swift`에 화면, 형상 생성, 텍스처 생성, 파일 저장 코드가 포함되어 있습니다.

## 포함된 기능

- SwiftUI 화면과 SceneKit의 3D 시편 미리보기
- 폭·깊이·전체 높이·층 수 설정, 벽 두께 40 mm
- 고정 시드로 1024 × 1024 RGB 텍스처 생성
- 텍스처 미리보기 전환
- OBJ·MTL·PNG·PLY·CSV와 데이터 설명 파일 저장 및 공유

이 코드는 가상 시편을 생성합니다. 실제 카메라나 LiDAR 데이터를 수집하는 ARKit 구현은 없습니다.

## 실행 순서

1. Xcode에서 **iOS → App** 프로젝트를 만듭니다. 인터페이스는 **SwiftUI**, 언어는 **Swift**로 선택합니다.
2. 프로젝트의 iOS 배포 대상을 **iOS 15.0 이상**으로 설정합니다. 소스에서 사용하는 버튼 스타일과 텍스트 선택 기능에 필요합니다.
3. 자동 생성된 `ContentView.swift`의 내용을 [제공된 소스](ConcreteLiDARPractice/ContentView.swift)로 교체합니다. 같은 이름의 View가 중복되지 않도록 새 파일을 추가하는 대신 기존 파일 내용을 교체합니다.
4. 자동 생성된 App 파일의 시작 화면이 `ContentView()`인지 확인합니다.
5. iPhone 시뮬레이터를 선택하고 **⌘R**로 실행합니다.
6. 치수와 층 수를 설정한 뒤 **시편 생성** 버튼을 누릅니다.
7. **OBJ + MTL + PNG + PLY + CSV 저장** 버튼으로 내보냅니다. 공유창을 닫아도 저장 파일은 유지됩니다.
8. 시뮬레이터에서 **저장 경로 복사**를 누르고, Mac Finder의 **⌘⇧G**에 붙여넣어 저장 폴더를 엽니다.

외부 패키지와 카메라 권한은 필요하지 않습니다. Xcode 프로젝트 파일 자체는 포함되어 있지 않습니다.

## 기본 설정과 기존 예제의 차이

| 항목 | Swift 원본 기본값 | 저장소의 기존 가상 예제 |
| --- | ---: | ---: |
| 폭 × 깊이 × 높이 | 500 × 500 × 150 mm | 500 × 500 × 150 mm |
| 층 수 | 5층 | 6층 |
| 층 높이 | 30 mm | 25 mm |
| 벽 두께 | 40 mm | 40 mm |

기존 예제 조건을 확인하려면 층 수를 6으로 바꾼 후 시편을 다시 생성합니다. 기존 예제 데이터는 그대로 보존했습니다.

## 저장 파일과 확인 사항

- OBJ·MTL·PNG는 같은 폴더에 원래 파일명으로 보관합니다.
- 텍스처 스위치를 꺼도 저장하는 OBJ에는 텍스처 연결이 포함됩니다.
- PLY는 색상 없는 XYZ 좌표이며, CSV는 가상 형상의 계산 치수입니다.
- 원본 코드에는 저장 파일 수를 6개로 표시하는 문구가 있으나, 실제 코드상 저장 대상은 설명 파일까지 **7개**입니다. 화면의 파일 수 문구와 실제 출력 목록에 차이가 있습니다.
- 실행 환경의 Xcode·macOS·시뮬레이터 버전과 빌드 재현 기록은 아직 문서화되지 않았습니다.
